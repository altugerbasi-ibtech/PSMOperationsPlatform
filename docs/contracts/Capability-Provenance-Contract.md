# Capability Provenance Contract

Status: **IMPLEMENTED — INTEGRATION PENDING**

Capability provenance safely references normalized evidence: source module,
fact category, stable fact key, InventoryRunId, InventoryVersion, and
capability RuleVersion. Decision provenance additionally records capability
code/category, support/readiness/evaluation status, reason code, and snapshot.

Raw CIM, registry output, localized provider output, credentials, connection
strings, tokens, tickets, and secrets are prohibited.
