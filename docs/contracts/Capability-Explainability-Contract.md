# Capability Explainability Contract

Status: **IMPLEMENTED — INTEGRATION PENDING**

Every capability and strategy outcome has a stable machine-readable reason
code and safe deterministic explanation. Decisions expose sorted satisfied,
blocking, unknown, invalid, and optional capability groups.

Explanations derive from decision semantics, not exceptions, localized
operating-system text, registry display strings, unordered collections, or raw
provider data. Unknown identifies unavailable evidence and remains distinct
from unsupported.
