# Windows Feature Collector Decision Rules

Status: **DEFERRED**

Purpose: document the potential future read-only Windows Feature diagnostics
strategy. WP-008.1 exposes normalized discovery facts but no approved aggregate
capability suitable for decision input, so WP-008.2 intentionally implements
no strategy and invents no capability.

Input capabilities, category, support/readiness requirements, priority,
reason codes, status, unknown/blocked/NotApplicable behavior, provenance, and
rule version remain deferred until an approved package defines the capability.
No feature is installed, removed, remediated, or executed. The Windows
Collector security boundary remains unchanged.
