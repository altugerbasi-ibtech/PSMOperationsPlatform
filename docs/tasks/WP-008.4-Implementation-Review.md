# WP-008.4 Implementation Review

Status: **Approved**

Implemented services:

- `ExecutionPolicyCatalog`, version 1;
- immutable runtime input/context/result and handler descriptor;
- explicit `CollectorExecutionHandlerRegistry`;
- `CollectorRuntime` with plan validation, dependency scheduling, bounded
  SerialCore/ParallelReadOnlyA groups, throttling limits, timeout, retry, and
  cancellation;
- version-1 typed lifecycle events and safe publication isolation;
- mutable Run, Step, and Attempt states with transitions and metrics;
- committed-plan loader, current-state store, and explicit orchestrator;
- forward migration `20260729041758_WP0084CollectorRuntime`.

Timeouts are 1/5/15 minutes. NoRetry uses one attempt.
StandardReadOnlyRetry uses two attempts with a deterministic one-second delay.
Parallel limits are 1/2; throttle limits are 4/2/1. Batching is inactive and
dependencies remain plan-declared only.

Tests use explicit fake handlers and in-memory state/event seams. They cover
policy resolution, registration validation, success, isolated failure, missing
handler, timeout, retry, cancellation, events, metrics, transition guards,
event failure, model constraints, and migration SQL.

Known limitations: production collectors and automatic startup wiring are
absent; cancellation-cooperative in-process handlers cannot be forcibly
terminated; durable events, monitoring, history, and distributed coordination
are deferred.
