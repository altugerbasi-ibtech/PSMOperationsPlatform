# WP-005.3 - Inventory Persistence Foundation

WP-005.3 implements normalized Windows current-state persistence without
inventory collection. `ManagedServer` is the target identity. Computer,
Operating System and Memory are single-state records. Processor, Disk and
Volume are independent collection snapshots. Network Adapter and IPv4 Address
form one atomic Network Snapshot under ADR-006.

Single-state stores insert or explicitly update. Collection stores materialize
and validate all input before deletion. Successful empty results clear owned
state; failed, cancelled or invalid results preserve the previous snapshot.
Each logical snapshot owns its persistence transaction. Network replacement
deletes IPv4 before adapters and inserts adapters before IPv4.

`CapturedAt` is application-owned Türkiye local time from `TimeProvider`.
Foreign keys use restrictive delete behavior. WP-005.1 defines no Disk-to-
Volume relationship, so those collections remain separate persistence units.

Migration `20260727230000_AddWindowsInventoryCurrentState` creates only the
eight WP-005.3 tables and is not automatically applied.

No collection commands, concrete modules, WinRM changes, history, generic
repository, packages, commit or push are included.
