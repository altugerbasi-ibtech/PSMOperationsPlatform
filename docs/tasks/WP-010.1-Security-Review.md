# WP-010.1 Security Review

## Status

Approved.

## Security boundary

The Portal uses the IIS default Windows Authentication scheme and deny-by-
default fallback authorization. Generic `/health` is the only explicit
anonymous endpoint and remains bounded and non-sensitive. No Basic, Forms,
cookie, bearer, custom login, identity header, WindowsIdentity construction,
impersonation, role/group model, secret, credential, or certificate bypass was
introduced.

Repository tests do not claim live IIS or HTTP Kerberos evidence. No individual
approver identity is recorded or inferred.
