## Implementation

The Web host registers `IISDefaults.AuthenticationScheme` through existing IIS
Integration. No production or authentication package reference was added. The
test-only `Microsoft.AspNetCore.TestHost` 10.0.9 reference was added for bounded
in-process HTTP behavior tests. Authorization uses
an authenticated-user fallback policy. `UseAuthentication` executes before
`UseAuthorization`, and both execute before endpoint mapping.

Generic `/health` remains explicitly anonymous, bounded, and non-sensitive. All
other mapped Portal endpoints inherit fallback protection. Tests prove 401 for
an anonymous protected request, success for a deterministic authenticated test
principal, and 403 for an authenticated principal denied by an explicit test
policy. The test scheme exists only in the test assembly and accepts no user
header or credential.

No Blazor services, role/group authorization, custom login, cookies, bearer,
Basic, Forms, Negotiate package, WindowsIdentity construction, impersonation,
identity-header trust, claims persistence/logging, exporter, or unrelated Portal
feature was added.
