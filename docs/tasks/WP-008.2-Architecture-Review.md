# WP-008.2 Architecture Review

Status: **IMPLEMENTED — INTEGRATION PENDING**

The Decision Engine boundary is a pure synchronous transformation from one
committed managed-target capability snapshot to one plan. It performs no
collector execution. Strongly typed decision, eligibility, and readiness
statuses preserve Unknown. Strategy/capability/plan versions are independent.

Eight explicit read-only rules use numeric priority/order and ordinal code
sorting. Safe provenance and deterministic explanations identify all evaluated
capabilities. Infrastructure atomically retains one current plan; input failure
preserves it and individual rule failure is isolated as Invalid.

The Windows Collector and SQL Collector identities remain separate. No
management strategy, target-side write, dynamic rule/plugin framework, raw
provider evidence, secret, or command is introduced. Future execution remains
a separate approval boundary.
