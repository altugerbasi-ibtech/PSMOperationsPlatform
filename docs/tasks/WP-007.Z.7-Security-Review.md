## Security boundary

Validation is read-only, secret-free, current-identity based, and preserves
Kerberos, Windows Authentication policy, SQL Integrated Security, encryption,
hostname validation and certificate validation. It accepts no credentials,
tokens or connection strings and reports no full configuration, HTTP body,
live metric, trace or certificate material.

Windows Authentication is still absent from Web-host composition and was not
implemented. No Basic/Anonymous authentication change, TLS bypass, exporter,
backend, permission change or remote mutation exists.

No individual approver identity is recorded or inferred.
