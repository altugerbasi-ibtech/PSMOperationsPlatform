# WP-008.6 Architecture Review

## Status

Approved.

## Boundary

The dependency-minimal SDK is a public contract inside the frozen Collector Plugin Boundary, not a new layer. Dispatcher owns explicit plugin resolution, descriptor normalization, Runtime–SDK compatibility, plugin validation, policy resolution/capability validation, context construction and submission. Runtime executes the supplied plugin and retains timeout, retry, throttling, dependencies, cancellation, events and mutable state.

Application references SDK; SDK references no Application, Infrastructure, EF Core, SQL, Windows host, WinRM or PowerShell implementation. Registration is explicit and ordinal. Dynamic loading, scanning, service-location and third-party trust are absent.

## Security and risks

All plugins are read-only and cancellation-aware and receive immutable SDK contracts only. Hello Collector is test/sample-only and infrastructure-neutral. SDK evolution requires explicit compatibility changes; in-process plugins must cooperate with cancellation. Signing, distribution, production target access and integration remain deferred.
