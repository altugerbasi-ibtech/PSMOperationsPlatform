# Development Workflow

1. Record product need.
2. Review scope and principles.
3. Add ADR if architecture changes.
4. Prepare Work Package.
5. Implement in a branch.
6. Build and test.
7. Review security, operations and maintainability.
8. Merge after acceptance criteria pass.

Codex implements specifications; it does not define architecture.
