# Introduction

PSM Operations Platform is a centrally hosted Windows infrastructure operations application. It uses Blazor for interaction, SQL Server for durable state and specialized Windows services for collection. It avoids commercial SaaS assumptions, multi-tenancy and generic provider frameworks.
