# System Goals

- Manage approximately 1,000 Windows servers.
- Avoid target agents.
- Separate Windows and SQL privileges.
- Support resilient periodic collection.
- Preserve command history and audit.
- Remain understandable to a small internal team.
- Grow only in response to proven needs.
