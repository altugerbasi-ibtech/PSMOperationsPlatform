# Terminology

| Preferred | Avoid | Meaning |
|---|---|---|
| PSM Operations Platform | PSM Lens | Product name |
| Windows Server | Host, machine | Managed Windows system |
| Collector | Agent | Central service; no target agent |
| Windows Collector | OS Collector | Windows, IIS, service, certificate and event log duties |
| SQL Collector | Database Collector | SQL Server duties |
| Windows Action Executor | Admin Collector | Future privileged executor |
| Command Queue | Job Bus | SQL-backed durable queue |
| Work Package | Task prompt | Approved implementation contract |
