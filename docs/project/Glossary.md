# Glossary

**Collector** — Windows Service that leases commands and performs discovery or monitoring.

**Lease** — Time-limited ownership of a queued command.

**gMSA** — Group Managed Service Account used to run services without manually managed passwords.

**Inventory** — Relatively slow-changing configuration and identity data.

**Metric** — Time-based operational measurement.

**Alert** — Persisted condition requiring attention.

**Audit Event** — Security-sensitive or operationally important activity record.
