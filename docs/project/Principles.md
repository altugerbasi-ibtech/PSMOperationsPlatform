# Engineering Principles

> Every abstraction must earn its place.

1. **Operations First** — Solve real operational problems.
2. **Keep It Simple** — Avoid speculative abstraction.
3. **Security by Design** — Security boundaries are architectural.
4. **Least Privilege** — Each identity receives only required permissions.
5. **Documentation Before Implementation** — Significant changes start with design.
6. **Small Work Packages** — Changes remain independently understandable and testable.
7. **Observable by Default** — Important work is measurable, traceable and auditable.
8. **One Source of Truth** — Each subject has one authoritative document.
9. **Consistency Over Cleverness** — Predictability beats novelty.
10. **Evolution Over Revolution** — Prefer controlled incremental change.
11. **No Hidden Magic** — Reflection and dynamic loading require explicit justification.
12. **Operational Safety** — Privileged actions require stronger controls than read-only collection.
