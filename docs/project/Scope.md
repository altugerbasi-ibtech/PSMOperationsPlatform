# Product Scope

## Version 1

- Windows Server inventory
- OS and role discovery
- CPU, memory, disk and selected network metrics
- Windows Service inventory and state
- IIS sites, applications, pools, bindings and worker processes
- SQL Server instances, databases, sessions, connections and selected health metrics
- Approved event log collection
- Certificate inventory and expiration alerts
- Dashboard, alerts, reports and audit
- Windows Authentication and AD group authorization
- Separate Windows and SQL collector identities

## Out of scope

- Linux
- Azure, AWS and generic cloud management
- VMware
- Docker and Kubernetes
- Oracle and PostgreSQL
- Multi-tenancy
- Public plugin SDK
- Runtime plugin loading
- Mobile application
- Public REST API
- Generic scripting engine
- Elasticsearch, Kafka and RabbitMQ
