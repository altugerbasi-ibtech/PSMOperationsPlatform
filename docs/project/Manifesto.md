# PSM Operations Platform Manifesto

PSM Operations Platform is built for enterprise IT operations teams managing Microsoft infrastructure.

The platform prioritizes operational usefulness, security, observability, maintainability and clarity.

Every feature must solve a real operational problem. Every component follows least privilege. Every architecture decision must make the system easier to operate, maintain or evolve.

PSM Operations Platform is an operations platform, not a framework.
