# Product Vision

PSM Operations Platform gives one IT department a unified view of the Windows infrastructure it operates.

The product should quickly answer:

- Which servers are unavailable?
- Which Windows Services are stopped?
- Which IIS sites or application pools are degraded?
- Which SQL Server instances or databases require attention?
- Which resources are approaching capacity?
- Which certificates are expiring?
- What changed recently?
- Who performed which action?

The target scale is approximately 1,000 Windows servers.
