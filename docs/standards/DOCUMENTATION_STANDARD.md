# Documentation Standard

## Purpose

This document defines the documentation standards used throughout the PSM Operations Platform repository.

Documentation is considered part of the product.

## Scope

This standard applies to every Markdown document in the repository.

## Documentation Principles

1. Single Source of Truth
2. Documentation Before Implementation
3. Keep Documentation Practical
4. Long-Term Maintainability
5. AI Friendly

## Writing Rules

- Use short paragraphs.
- Use ATX headings.
- Always specify code block language.
- Prefer Mermaid diagrams.
- Use consistent terminology.
