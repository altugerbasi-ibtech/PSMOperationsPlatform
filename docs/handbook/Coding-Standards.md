# Coding Standards

- Enable nullable reference types.
- Prefer explicit readable code.
- Avoid service locators.
- Use async I/O and CancellationToken.
- Use typed options.
- Do not create interfaces without a real substitution or test seam.
- Keep Domain independent of EF Core, web and collector libraries.
