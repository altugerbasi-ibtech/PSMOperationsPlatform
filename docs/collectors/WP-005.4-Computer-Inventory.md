# WP-005.4 - Computer Inventory

`ComputerInventoryModule` runs after a successful probe through the existing
reusable WinRM command session. It executes two allowlisted object projections:

- `Get-CimInstance -ClassName Win32_ComputerSystem -Property
  Name,Domain,Manufacturer,Model`
- `Get-CimInstance -ClassName Win32_BIOS -Property SerialNumber`

Each command must return exactly one record. `Name` is required. Optional
strings, when present, must be non-whitespace and within the entity maximum
length. Leading/trailing whitespace and over-length values are rejected rather
than corrected or truncated.

The normalized result maps to `ComputerInventoryState`. `Fqdn` remains null
because this Work Package does not project a reliable FQDN source property.
Only a fully valid result is passed to `IComputerInventoryStore`.

Failure is reported by the existing orchestrator and performs no persistence.
The module creates no session and changes no timeout or retry behavior.
