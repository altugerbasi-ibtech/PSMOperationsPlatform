# SQL Collector

Connect using Windows integrated authentication. Responsibilities include connectivity test, instance metadata, databases, sessions, connection summaries, blocking, selected waits, database file utilization and IIS-to-SQL correlation data.

The identity must not have Windows administration rights on targets.
