# WP-005.4 - Operating System Inventory

`OperatingSystemInventoryModule` executes one allowlisted projection:

`Get-CimInstance -ClassName Win32_OperatingSystem -Property
Caption,Version,BuildNumber,OSArchitecture,InstallDate,LastBootUpTime`

The command returns objects, not formatted or human-readable text. Exactly one
record is required. Caption, Version, BuildNumber and OSArchitecture are
required and length-validated. InstallDate and LastBootUpTime are optional
timestamps; non-timestamp values and sentinel minimum/maximum timestamps are
rejected. `DateTimeOffset`, UTC `DateTime` and local `DateTime` values are
converted through `TimeProvider.LocalTimeZone`; an unspecified `DateTime` is
treated as an already-local CIM value. Persistence rejects UTC-kind source
timestamps so repository `datetime2` values retain one local-time semantic.

The result maps explicitly to `OperatingSystemInventoryState`; Edition and
TimeZoneId remain null because they are outside this projection. Persistence
uses `IOperatingSystemInventoryStore` only after complete validation.
