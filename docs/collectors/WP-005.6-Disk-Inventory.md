# WP-005.6 - Disk Inventory

`DiskInventoryModule` reuses the successful WinRM session and runs an explicit
`MSFT_Disk` CIM projection for UniqueId, Number, FriendlyName, SerialNumber,
Size, BusType and PartitionStyle.

`UniqueId` is the target-scoped `StableSourceKey`. Microsoft defines inherited
`MSFT_StorageObject.UniqueId` as required logical-object identity across
provider instances. Disk Number is not identity because Windows documents that
it may change across restarts.

References: [MSFT_StorageObject](https://learn.microsoft.com/en-us/windows-hardware/drivers/storage/msft-storageobject)
and [MSFT_Disk](https://learn.microsoft.com/en-us/windows-hardware/drivers/storage/msft-disk).

`UniqueId` is provider-supplied rather than a platform-generated hardware
identity. Hardware replacement, storage presentation changes or provider
remapping may change it; replace-all intentionally treats the changed value as
a new current source identity.

Number and Size must be non-negative. Strings are not trimmed or truncated.
BusType and PartitionStyle numeric values map through explicit documented
allowlists. Unknown values fail. Blank, over-length or duplicate UniqueId fails
before persistence. Successful empty calls the existing Disk store with an
empty collection; failure and cancellation preserve prior state.
