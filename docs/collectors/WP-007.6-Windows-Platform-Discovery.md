# WP-007.6 — Windows Platform Discovery

Status: **APPROVED — INTEGRATION PENDING**

## Repository implementation

WP-007.6 adds independent current-state modules for Windows Roles, Windows
Features, IIS platform capability, .NET platform installations, and Windows
PowerShell/PowerShell 7 installations. All collection uses explicit,
PowerShell 5.1-compatible projections on the core pipeline's one shared
Kerberos session.

The repository includes deterministic normalization and validation, five
current-state persistence tables, an operator-controlled forward migration,
atomic replacement through the complete-core transaction, and deterministic
tests. No websites, applications, bindings, application pools, binaries, or
application configuration are inspected.

## WP-007.Z checks

- Apply the complete migration chain to a clean approved lab database.
