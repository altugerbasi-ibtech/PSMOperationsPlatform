# WP-005.4 - Memory Inventory

`MemoryInventoryModule` executes:

`Get-CimInstance -ClassName Win32_ComputerSystem -Property
TotalPhysicalMemory`

Exactly one object is required. `TotalPhysicalMemory` must be an integral,
non-negative value that fits in `Int64`; null, non-integral, negative and
overflowing values are rejected. The normalized byte count is passed to
`IMemoryInventoryStore`.

Invalid or failed collection never calls the store and therefore preserves the
previous successful current-state record.
