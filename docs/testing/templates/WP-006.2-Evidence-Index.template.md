# WP-006.2 Evidence Index

## Execution identification

| Field | Value |
|---|---|
| Execution ID | `<REQUIRED>` |
| Change reference | `<REQUIRED>` |
| Start/stop time | `<REQUIRED>` |
| Result | Planned / Stopped / Completed |

## Approvals

Operator, approver, rollback owner, maintenance window, Server 2019 lab-only
exception (if applicable), HTTP fallback decision and each service-control
approval.

## Repository and artifact

Repository commit, Collector executable path, SHA-256 and installation path.

## Readiness

Readiness JSON path/hash, status, exit code, warnings and approval.

## Preflight

Preflight JSON/Markdown path/hash, result and unresolved findings.

## Service evidence

Pre-execution state, SCM metadata, account, path, start approval, Running
snapshot, stop approval, PostStop snapshot and restored state.

## Host/process evidence

OS, timezone, PowerShell, PID, start time, memory, handles and threads.

## Logging evidence

Original configuration/hash, approved Debug values, captured log files/event
query specification, correlation IDs, access control and restored hash.

## SQL baseline

Baseline JSON/CSV paths/hashes, migration, connectivity state, counts,
duplicates and orphan result.

## SQL post-run

PostRun JSON/CSV paths/hashes, counts, stable keys and capture ranges.

## SQL integrity verification

Verification JSON/CSV paths/hashes; singular duplicates, stable-key duplicates
and IPv4 orphan counts.

## Target and transport evidence

Approved `ManagedServerId`, target FQDN, isolation proof, configured policy,
attempted/selected transport and HTTP fallback approval.

## Graceful stop

Approval, request time, completion time, shutdown log and final process/service
state.

## Restoration

Logging restoration, service-state restoration, any operator-managed isolation
rollback, hashes and rollback-owner signoff.

## Deviations

List every unexpected result. Partial target success is a deviation and cannot
be recorded as the qualifying clean happy path.

## Security/redaction review

Confirm restricted storage and absence of credentials, connection strings,
tokens, raw exceptions and unnecessary topology.

## Final reviewer decision

`READY_FOR_REVIEW`, `WARNING` or `NOT_READY`, reviewer, time and rationale.
