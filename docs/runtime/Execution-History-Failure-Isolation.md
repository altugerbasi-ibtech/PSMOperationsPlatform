# Execution History Failure Isolation

History uses explicit input, schema, projection, persistence, concurrency,
duplicate, sequence, artifact, policy, query, availability, cancellation, and
unexpected categories.

Public results contain only bounded codes. Database exception text, stack
traces, target failure, connectivity, authentication, plugin failure, and
Runtime timeout are not substituted. History cannot trigger retry,
cancellation, remediation, or state/plan/context mutation.
