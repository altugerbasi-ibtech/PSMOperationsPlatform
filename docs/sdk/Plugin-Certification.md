# Plugin Certification Metadata

Certification does not determine monitoring readiness; both are advisory and
remain distinct.

Status: **IMPLEMENTED — ADVISORY**

Schema version 1 supports `Experimental`, `Verified` and `Certified`.
Certification authority, time, reference and safe notes are optional except
that Certified requires an authority and explicit time. Repository samples are
Experimental.

Certification is descriptive metadata, not cryptographic trust, signing,
deployment approval, compatibility, policy, eligibility or a quality score.
Dispatcher validation remains authoritative.
