# Authorization

Authorization is permission-based. AD groups map to application roles; roles map to permissions such as `Servers.View`, `Services.Restart`, `Iis.Recycle`, `Sql.View`, `Alerts.Manage` and `Administration.Manage`. UI checks alone are never sufficient.
